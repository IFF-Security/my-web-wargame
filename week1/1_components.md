# 웹 페이지의 구성요소

- [Webbrowser](#webbrowser)

## HTML/CSS/JS

* HTML: 웹 페이지의 내용물(Contents)를 나타내는 마크업 언어
    - 태그와 속성, 텍스트로 내용물을 구성함.
    - 여는 태그와 닫는 태그로 둘러싸인 블록을 요소(Element)라고 함.
* CSS: 웹 페이지의 디자인을 설정하는 스타일 시트 언어
    - 셀렉터(Selector)와 속성, 값으로 HTML의 요소(Element)를 꾸밈.
    - HTML의 style 요소로도 동일한 효과를 낼 수 있음.
* JS: 웹 페이지의 상호작용을 설정하는 프로그래밍 언어
    - javascript 프로그래밍 언어로 HTML의 동적 기능들을 처리함.
    - HTML의 script 요소로도 동일한 효과를 낼 수 있음.

## Webbrowser

웹에서 페이지를 검색하고 표시하며, 하이퍼링크를 통해 추가 페이지에 접근할 수 있게 하는 프로그램.

## JS Obfuscation

* JS는 기본적으로 클라이언트에서 실행됨. <br>
  -> 때문에 사용자가 웹 페이지에 접근하면, 해당 페이지의 스크립트를 전부 볼 수 있음.
* 이로 인한 스크립트의 유출을 막기 위해 JS 코드를 난독화(Obfuscation)하는 기법.
