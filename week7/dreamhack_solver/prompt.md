    - 메시지의 길이를 줄이기 위해, 공격 순서의 1~4번에 관한 내용은 4번 과정까지 전부 진행한 후 핵심 내용(플래그 위치, 핵심 취약점 등)만 출력해주세요.
    - 서버코드의 언어에 대한 기본적인 지식을 최대한 활용해주세요.
        - 예를 들어, JS에서 innerHTML을 수정하는 경우, 해당 내용 안에 포함되어있는 script 태그는 재실행되지 않습니다.
    - 서버코드를 포함해, 서버의 실제 루트는 프로젝트의 루트와 다를 수 있습니다. 프로젝트를 충분히 탐색하고 프로젝트의 루트 디렉토리를 설정해주세요.

    4. 프로젝트의 서버코드에서 모든 Route에 대한 세부 로직을 꼼꼼히 분석해주세요. 취약점이 있다면, 해당 취약점을 사용할 수 있는 방법까지 생각해주세요.
