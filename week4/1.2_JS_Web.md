## XMLHttpRequest (XHR)
* 클라이언트단에서 서버와 상호작용하기 위한 클래스
* 페이지의 새로고침 없이 URL로부터 데이터를 받아올 수 있음
* 다만, 환경에 따라 변수가 많기에, 후술할 더 발전된 형태인 Fetch API를 사용하는 것을 권장
  - 또한 요청의 정보를 작성하는 부분과 요청을 실제로 보내는 부분이 다르고, request의 결과 데이터를 이벤트 안에서 처리하는 등 사용 방법이 fetch에 비해 복잡하고 비직관적이기에 Fetch API를 사용하는 것이 좋다.
* 사용법
  ```js
  // 0. XHR 객체 생성
  const XHR = new XMLHttpRequest();
  
  // 1. Request 정보 설정
  XHR.open('GET', '/api');
  // 3번째 파라미터로 비동기 요청을 보낼지 설정 가능. 기본값: true
  // 인증 정보가 필요하다면, 4/5번째 파라미터로 username와 password를 지정할 수 있음

  // 2. 값을 전부 받아왔을 때 처리할 코드를 작성
  XHR.onreadystatechange = function() {
    if (XHR.readyState == XMLHttpRequest.DONE && XHR.status == 200) {
    	console.log(XHR.responseText);
    }
  };

  // 3. 완성한 Request 전송
  XHR.send();
  ```

## Fetch API
* 위에서 서술한 XHR보다 발전한 형태의 HTTP 비동기 통신 라이브러리
* `fetch(url, options)` : 매개변수로 요청을 보낼 URL과 요청의 옵션을 전달하고, 해당 요청에 대한 Promise 객체를 Return하는 함수
* API 호출이 성공했다면 Response 객체를 resolve하며, 실패했다면 관련 Error 객체를 reject 한다.
  - 주의점: fetch는 네트워크 오류 등 **함수의 동작 자체가 실패한 경우**에만 해당 Error를 reject한다.
  - 404, 502 등 HTTP 오류는 통신 자체는 성공했으나 그 결과에 오류가 있는 경우이기 때문에, resolve된 후 `resp.ok`를 통해 HTTP 오류가 있는지 확인해야 한다.
* 사용법
  ```js
  // 1. Promise style

  fetch("https://jsonplaceholder.typicode.com/todos/1")
    .then(resp => resp.json())
    .catch(console.error)
      .then(console.log);

  // 2. async-await style
  (async () => {
    try {
      const resp = await fetch("https://jsonplaceholder.typicode.com/todos/1");
      const json = await resp.json();
      console.log(json);
    } catch (e) {
      console.error(e);
    }
  })();
  ```

## Axios
* fetch와 마찬가지로, HTTP 비동기 통신을 위한 라이브러리
* JS의 built-in library인 fetch와 달리 built-in 기능이 아니다.
  - 때문에 사용 전에 해당 라이브러리의 설치가 필요하다.
  - 설치 방법
    - node.js (npm): `npm i axios`
    - Browser (unpkg CDN): `<script src="https://unpkg.com/axios/dist/axios.min.js"></script>`
* 일부 차이를 제외하면 fetch와 비슷함
  - 후술할 사용법이 fetch와 조금 다름
  - 함수 내부에서 자동으로 직렬화/비직렬화해줌 (option으로 설정 가능)
    - 직렬화(Serialization): object를 하나의 buffer에 연속된 비트 단위로 저장하는 과정
    - 역직렬화(Deserialization): 직렬화되어있는 buffer를 다시 object로 만드는 과정
* 사용법
  - `axios(options);` ; options에 url, method, header, data 필드를 기입하여 사용 (method 필드 기본값: `GET`)
  - `axios.[method](url[, data[, config]])` ; 좀 더 직관적인 버전
  ```js
  axios({
    url: 'https://jsonplaceholder.typicode.com/todos/1',
    method: 'GET'
  }).then(console.log);

  axios.get('https://jsonplaceholder.typicode.com/todos/1')
    .then(console.log);
  ```

### 각 API의 주 사용처
* Legacy Web: 서버의 환경(낮은 JS 버전 등)과 같은 의존성때문에 XHR를 주로 사용
* Modern Web: 코드 다이어트를 위해 fetch를 주로 사용
* 복잡한 API Call이 필요한 서비스: API Call에 디테일한 설정을 제공하는 Axios를 주로 사용
